Saving videos offline: a practical guide

Seven services, one honest answer for each. Written for use on your own phone and computer.

Every fact here was checked against the official pages listed at the bottom on 16 November 2026. Apps and sites change often. If something here does not match what you see, trust the app.

yt-dlp is free, open-source software that runs on your own device. It is the tool this page recommends for the first four services. The last three services protect their video with DRM, so the only route covered here is each service’s own app.

Why your own device works and a cloud server does not

YouTube and Instagram treat a request from a cloud server’s address as suspect, but treat a request from a home or mobile connection like a normal viewer. yt-dlp maintainers say this about YouTube in the project’s issue tracker: YouTube “blocked anonymous access from many datacenter IPs”.

I found no official page that explains the same thing for Instagram. Your test failed on both, so the cause looks the same. Running yt-dlp on your own phone or computer sends the request from your own internet connection, which is the address these sites accept.

Install yt-dlp, ffmpeg and a JavaScript runtime

You need three things.

  • yt-dlp does the downloading.
  • ffmpeg (with ffprobe) joins separate video and audio files and converts to mp3. yt-dlp calls it “strongly recommended”. You will want it.
  • A JavaScript runtime, for YouTube. YouTube sends puzzles that yt-dlp must solve with JavaScript. yt-dlp’s own scripts for this are bundled in the official downloads. The runtime itself is separate. yt-dlp prefers Deno (version 2.3.0 or newer) and enables it by default. Node.js 22 or newer also works if you switch it on with --js-runtimes node. QuickJS and Bun (deprecated) are the other options.

You are a developer, so you may already have Node.js 22 or newer. Run node --version. If it shows 22 or higher, you can skip Deno and use the Node line shown under each system below.

Linux

This uses the release file from yt-dlp. It needs Python 3.11 or newer. Ubuntu’s own yt-dlp package is not the one the project documents, so use the release file.

mkdir -p ~/.local/bin
curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -o ~/.local/bin/yt-dlp
chmod a+rx ~/.local/bin/yt-dlp

If you have no Python, download the standalone file yt-dlp_linux (64-bit Intel/AMD, glibc 2.17 or newer) from the releases page instead.

Install ffmpeg. This is the Ubuntu and Debian command, from the official packages FFmpeg’s download page lists.

sudo apt install ffmpeg

Install a JavaScript runtime. Pick one.

# Option A: Deno, using Deno's own install script
curl -fsSL https://deno.land/install.sh | sh

# Option B: use Node.js 22 or newer that you already have
mkdir -p ~/.config/yt-dlp
echo '--js-runtimes node' >> ~/.config/yt-dlp/config

Deno’s documentation says it does not publish an official apt repository, so use the script. Open a new terminal afterward, then check:

yt-dlp --version
ffmpeg -version
deno --version

Windows

Open PowerShell and run these three lines. They use the commands from the yt-dlp wiki, Deno’s documentation and the winget catalogue.

winget install --source winget --id yt-dlp.yt-dlp
winget install Gyan.FFmpeg
winget install DenoLand.Deno

Close PowerShell and open it again so the new programs are found. Then check:

yt-dlp --version
ffmpeg -version
deno --version

If you prefer to download by hand, the file to get is yt-dlp.exe from the releases page. yt-dlp also publishes its own ffmpeg builds at github.com/yt-dlp/FFmpeg-Builds.

macOS

You need Homebrew. Homebrew’s yt-dlp package lists Deno as a dependency, so it should install Deno for you.

brew install yt-dlp ffmpeg
yt-dlp --version
ffmpeg -version
deno --version

If deno --version says “command not found”, run brew install deno.

Android

The documented route is Termux, a terminal app. The Termux project says to get it from F-Droid or from its GitHub releases. Its Google Play build is marked experimental, with missing functions and bugs. Then run these lines inside Termux. They follow the yt-dlp wiki’s Termux steps, plus ffmpeg and Node.js from the Termux package list.

termux-setup-storage
pkg update && pkg upgrade
pkg install python python-pip ffmpeg nodejs
pip install -U "yt-dlp[default]"
mkdir -p ~/.config/yt-dlp
echo '--js-runtimes node' >> ~/.config/yt-dlp/config

termux-setup-storage asks for permission to use your phone’s storage. Afterward, ls ~/storage shows the folders you can save into. To save into your phone’s downloads folder, add -P ~/storage/downloads to the commands below (check the folder name with ls first).

If you do not want a terminal, see Easier apps.

Commands for common jobs

Replace URL with the link, and keep the quotes around it. Quotes stop your shell from breaking links that contain & or ?. These work the same on Linux, macOS, Windows and Termux. Tap or click a block to select all of it.

Best quality

yt-dlp "URL"

This picks the best video and audio and joins them with ffmpeg. The file may come out as .webm or .mkv.

Best quality as an mp4 that plays anywhere

yt-dlp -t mp4 "URL"

-t mp4 is a built-in preset. It makes an mp4 and prefers H.264 video and AAC audio, which most phones and TVs play. It puts the codec first, so it can pick a lower resolution than the very best stream.

Cap the quality at 1080p

yt-dlp -S "res:1080,vcodec:h264,acodec:aac" --merge-output-format mp4 "URL"

This asks for the best video up to 1080 pixels high, and prefers H.264 and AAC within that. Use res:720 for 720p. To see every format a link offers, run yt-dlp -F "URL".

Audio only, as mp3

yt-dlp -t mp3 "URL"

This needs ffmpeg and ffprobe. The longer form is yt-dlp -x --audio-format mp3 "URL".

A whole playlist

yt-dlp --yes-playlist -o "%(playlist)s/%(playlist_index)s - %(title)s.%(ext)s" "PLAYLIST_URL"

This puts the files in a folder named after the playlist, numbered in order. If a link points to one video inside a playlist and you want only that video, use --no-playlist.

To make long jobs restartable, add --download-archive archive.txt. yt-dlp then skips anything already listed in that file. To go gently on the site, add -t sleep, a preset that waits between requests. YouTube’s “try again later” error comes from asking too fast; the yt-dlp wiki suggests a 5 to 10 second delay between downloads.

Subtitles

yt-dlp -t mp4 --write-subs --write-auto-subs --sub-langs "en.*" --embed-subs "URL"

--write-subs saves uploaded subtitles. --write-auto-subs adds automatic captions. --sub-langs "en.*" picks every English variant. --embed-subs puts them inside the file, which works for mp4, mkv and webm. To get separate .srt files instead, drop --embed-subs and add --convert-subs srt.

Instagram, X and Reddit

Use the same commands with a post, reel or tweet link. Single posts, reels and stories are the normal case. yt-dlp’s supported-sites list marks Instagram user profile downloads as “Currently broken”, so do not expect to save a whole profile in one go.

Using your browser’s sign-in

Some posts are visible only to a signed-in person. yt-dlp can read the sign-in cookies your browser already holds, so it looks like you. Add this to any command above:

yt-dlp --cookies-from-browser firefox "URL"

Replace firefox with your browser: brave, chrome, chromium, edge, opera, safari, vivaldi or whale. To pick a browser profile, write BROWSER:PROFILE. You must be signed in to the site in that browser first.

Read this before using it.

  • Cookies are like a saved password. Anyone who holds them can act as you. Never share them, and never put a cookie file in a repository or a chat.
  • The cookies it reads cover every site you are signed in to, not only the one you named. The yt-dlp FAQ says that exporting cookies this way exports your browser’s cookies for all sites.
  • Using your account with an automated tool can get the account limited. The yt-dlp wiki says plainly that for YouTube you run the risk of the account being banned, temporarily or permanently. Use it only when you must, and slow down with -t sleep.
  • It works on a computer. Termux on a phone cannot read your phone browser’s cookies. If a post needs sign-in, do that download on the computer.

When you need it

  • Instagram: often. If yt-dlp says login is required, add the option. This is how it behaves in practice. I found no official page that lists which Instagram posts need it.
  • Reddit: sometimes. Try without it first, and add it if yt-dlp says it needs a login.
  • X: only if yt-dlp says a login is needed for that post.
  • YouTube: only for content that needs an account, such as age-restricted videos, private playlists and members-only videos. Normal public videos do not need it.

YouTube is different

The yt-dlp wiki says not to use --cookies-from-browser for YouTube. YouTube rotates cookies on any tab that stays open, so the browser’s cookies stop working quickly. The wiki’s method is to export a cookie file from a private window. In short:

  1. Open a new private or incognito window and sign in to YouTube.
  2. In that same tab, open youtube.com/robots.txt. Keep it the only private tab.
  3. Export the youtube.com cookies with a cookie-export extension. The FAQ names “Get cookies.txt LOCALLY” for Chrome and “cookies.txt” for Firefox. It warns that the older “Get cookies.txt” (without LOCALLY) was reported as malware, so avoid it.
  4. Close the private window. Then run:
yt-dlp --cookies youtube-cookies.txt "URL"

The wiki also suggests a throwaway account where you can. Treat the file as a password and delete it when done.

When a site stops working

Sites change their code often, and yt-dlp changes to keep up. In almost every case the fix is a newer yt-dlp. Update first, then try again.

# release-file installs (Linux, Windows, macOS)
yt-dlp -U

# the yt-dlp README recommends the nightly channel for regular users
yt-dlp --update-to nightly

If you installed another way, update the same way:

# pip, and Termux on Android
python3 -m pip install -U "yt-dlp[default]"
# in Termux, use:  pip install -U "yt-dlp[default]"

# Homebrew (macOS)
brew upgrade yt-dlp

# winget (Windows)
winget upgrade --source winget --id yt-dlp.yt-dlp

If YouTube still fails after an update, check these in order:

  1. Is a JavaScript runtime installed? Run deno --version (or node --version if you use Node).
  2. Is it new enough? Deno 2.3.0 or later, Node 22.0.0 or later.
  3. Did you set --js-runtimes node if you use Node? Only Deno is on by default.
  4. Are you on a cloud server or a VPN? See above. Try your home connection.
  5. Did you see 429, or “try again later”? You asked too fast. Wait, and add -t sleep.

Easier apps

These apps wrap yt-dlp or do similar work. I checked each project’s own page and its recent activity on 16 November 2026. Download them only from the places the project itself names.

Android

  • YTDLnis. Free, open source (GPL-3.0), for Android 7.0 and newer. It uses yt-dlp and says it can download from more than 1000 sites. Playlists, queues and subtitles are included. Latest release v1.9.1.1 on 19 October 2026, and code changes continue. Get it from F-Droid, IzzyOnDroid or the project’s GitHub releases. The project says those are the only trusted sources. Keep it updated, because it relies on yt-dlp.
  • NewPipe. Free, open source (GPL-3.0). It is a YouTube front-end that can also download videos, audio and subtitles. Its services are YouTube and YouTube Music, PeerTube, Bandcamp, SoundCloud and media.ccc.de. It does not cover Instagram, X or Reddit. Latest release v0.29.3 on 10 November 2026. The project calls the app beta. Install it from F-Droid (using NewPipe’s own repository) or from GitHub, comparing the signing key with the one listed on the project page.
  • Seal. I do not recommend it. It is a yt-dlp-based Android app, but its last stable release is v1.13.1 from October 2024, and I saw no code changes after April 2025. I could not confirm it is maintained.

Windows, macOS and Linux

  • Open Video Downloader. A desktop app around yt-dlp, with no command line. Free and open source (AGPL-3.0). It handles playlists, subtitles, audio-only and quality choices, can use a browser cookie file, and says it keeps both itself and yt-dlp updated automatically. Latest release v3.2.1 on 5 July 2026. Download it from the project’s GitHub releases page. The project recommends that over the Microsoft Store copy, because store updates arrive later and yt-dlp does not auto-update there.
  • ytDownloader. A desktop app for Windows, macOS and Linux, free and open source (GPL-3.0). It is under active development; latest release v4.1.0 on 11 November 2026. On macOS its README says you must install yt-dlp separately with Homebrew, and the macOS app is unsigned, so the README gives extra steps to open it.

I could not confirm from these projects’ pages how each handles YouTube’s JavaScript requirement. If YouTube fails in an app, update the app first. The command-line route above is the one yt-dlp itself documents.

Official routes: YouTube, Instagram, X, Reddit

These are the services’ own download features. They are the safest choice when they cover what you want. They work only inside the service’s own app or site.

YouTube Premium offline downloads

  • Who: you must be signed in. In most places this needs YouTube Premium. YouTube’s help also lists some countries where some videos can be downloaded without it. Check the app to see whether a given video shows a Download button for you in India.
  • Phone or tablet: open the video in the YouTube app and tap Download below it. Set the quality under Settings, Background & downloads, Download quality. You can limit downloads to Wi-Fi.
  • Computer: sign in to a Premium account at youtube.com in Chrome, Edge, Firefox or Opera, open the video and click Download. Find downloads under Downloads in the left menu.
  • Limits: downloads play offline for up to 29 days. After that the device must reconnect to the internet. In some countries the limit is 48 hours. The downloaded files are stored encrypted and play only inside the YouTube app. Some videos have no Download button. You cannot download more if less than 5% of storage is free. The help page does not give a device limit.
  • Audio: YouTube’s help says you cannot download audio, music or MP3 files from the YouTube app.

Instagram

  • Public reels: Instagram’s help says anyone can download a public account’s reel unless the creator turns off reel downloads, in account settings or on that reel. Look for a Download option in the reel’s share or options menu in the app. The exact label can differ by app version. Check in the app.
  • Private accounts: not downloadable by others. Instagram lists no one for private accounts.
  • Your own content: you can save your own reel drafts and your own stories to your camera roll. A download of your own reel does not include music you added from Instagram’s music library.
  • All your data: Instagram also lets you export a copy of your own information from your account settings.

X (Twitter)

  • Who: X Premium subscribers, including the Plus, Premium, Super and Ultra plans of The X Subscription, can download videos from certain posts. Not every video qualifies.
  • How: open the video, tap the three-dot icon and choose “Download video”.
  • Limits: videos uploaded since 25 July 2023 can be downloaded unless the uploader turned off “Allow video to be downloaded”. Older videos cannot. Accounts under 18 have downloads switched off.
  • Check in the app. I could read X’s help page only through a search result, because the site refused my direct request.

Reddit

I found no Reddit help page about downloading a video file. Reddit has a Save feature, which keeps a post in your account. I did not find any page saying it keeps the video file offline. Use yt-dlp for Reddit videos you are allowed to keep.

Netflix, JioHotstar and Amazon Prime Video

These three services protect their streams with DRM. This page covers only each service’s own offline feature in its own app. It does not cover anything else, because that breaks the services’ terms and, in many places, the law.

Downloaded titles stay inside the app, expire, and are tied to your account. That is how the official feature works.

Netflix

  • Devices and apps: the Netflix app on an Android phone or tablet, an iPhone or iPad, an Amazon Fire tablet, or a Chromebook with the Google Play Store. Netflix’s help page for downloads does not list Windows, Mac or web browsers. Some older operating system versions do not support downloads. Update the app first.
  • How: on a phone or tablet, open My Netflix, then Downloads, then “See What You Can Download”. Or tap the download button on a title’s page. Movies have one button. For a show, download single episodes or a whole season. On a Chromebook, go to Downloads, then Find More to Download.
  • Plans and devices: Netflix’s plans page says how many devices can hold downloads at a time: Mobile, 1 phone or tablet. Basic, 1. Standard, 2. Premium, 6. Check your own plan in your account.
  • Limits: up to 100 active downloads per device on ad-free plans. On ad-supported plans the cap is 15 downloads per device per calendar month, on 2 devices. The count resets on the first of the month. Ad-supported plans also lack the “Downloads for You” and “Download Next Episode” features.
  • Expiry: downloads expire after a period of time. Netflix’s help does not say how long, so check in the app. You can replay a download as often as you like until it expires. To renew an expired download, delete it and download it again. A title that has left Netflix cannot be renewed. Some titles also limit how many times they can be downloaded or renewed, for example per year.
  • Titles you cannot download: not every show or movie is available. Netflix gives reasons such as rights that are exclusive to another company, rights it cannot buy, or other local factors.
  • Other: downloads belong to the device that downloaded them, and any profile on it can watch them. Higher-rated titles may not show on Kids profiles. If you cancel your account, the downloads on your device are deleted.

JioHotstar

  • Devices and apps: the JioHotstar app on iOS and Android, on a phone or tablet. You cannot download on a laptop or a TV. Update the app first.
  • How: open the film or episode, then tap the downward arrow below its thumbnail. Choose a quality.
  • Quality by plan: Mobile plan, HD 720p or Low 480p. Super and Premium plans, those two or Full HD 1080p. To set a default, open the profile icon, then Help & Settings, Downloads, Default Download Video Quality.
  • Expiry: downloads stay while you are an active subscriber and connect the device to the internet at least once every 30 days. A title can also expire when its rights on the platform end.
  • Number of titles: JioHotstar’s help says you can download unlimited titles, depending on your storage.
  • Limits: downloaded content is deleted if you reinstall the app or clear its data. If you are outside India, the download option and downloaded content are not available. Keep the app open while a download runs.
  • Titles you cannot download: if a title shows no download option, JioHotstar does not have download rights for it. Most content has them, but not all.
  • Plans and rules change. Check the app for what your plan allows.

Amazon Prime Video

  • Devices and apps: an Amazon Fire tablet, or the Prime Video app on iOS, Android, macOS or Windows 10 and 11.
  • How: open the app, find the title and choose the download option on its details page. For a show, you can download a whole season, or single episodes with the download icon in the episode list.
  • Where it saves: in the Android and Windows apps you can choose the storage location. Amazon does not recommend saving to USB-connected drives.
  • Devices: for Prime subscription titles, you can download to two devices at one time. Prime Video Mobile Edition allows a single Android or iOS device. Purchased titles can go to four compatible devices. A rented title can be downloaded to only one device.
  • Number of titles: Amazon sets a maximum number of downloaded titles at a time across your account. It may vary by location. The Usage Rules do not give a number for India. Check the app.
  • Expiry: for subscription titles you typically have 30 days to start watching and 48 hours to finish once you press play. Rentals also typically give 48 hours once started, and must be finished before the rental window ends, usually 30 days after payment. Downloads of subscription titles stop when your membership ends.
  • Titles you cannot download: each title’s page says whether it can be downloaded. Free videos are not available for download.
  • Other: playing a downloaded title over Chromecast or AirPlay is not permitted.
  • The Usage Rules page I read is not specific to India, and it says limits can vary by location. Treat the numbers as a guide and check the app.

What is fair to download

  • Your own uploads. Videos you made and posted are yours to keep a copy of.
  • Videos the owner lets you save. That means the owner switched on a download option, or gave you permission, or published under a licence that allows copies.
  • Personal offline viewing, where the service’s terms permit it. The official offline features above are the clearest case. Do not re-upload or share what you save.

YouTube. YouTube’s Terms of Service say you may not “access, reproduce, download” content except as the service expressly authorizes, or with YouTube’s written permission. Downloading from YouTube with a third-party tool is therefore against YouTube’s terms of service. That is true even though yt-dlp itself is legitimate open-source software. The risk is to your account, and the terms say that is a breach. Use the official Premium download when it covers you.

I did not check the terms of Instagram, X or Reddit. Read them before you save anything you do not own.
