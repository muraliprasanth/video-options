# Saving videos offline

One page of options for saving videos for offline viewing on your own devices: yt-dlp for YouTube,
Instagram, X and Reddit, and each app's own offline download for Netflix, JioHotstar and Prime Video.

Served by GitHub Pages. Every claim on the page was checked against the official page linked at the
bottom on 16 November 2026. Things change: recheck before relying on it.

## Versions

The site shows its version (`VERSION`, now 1.0.0; git tag `v1.0.0`). `CHANGELOG.md` lists what each
version changed and how to number a new one with `tools/release.py`.
